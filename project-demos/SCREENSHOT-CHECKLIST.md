- [ ] Look at the page - does it look good? (cards visible, nice layout)

## Quick Reference

**Keyboard Shortcut**: `Cmd + Shift + 4`, then `Space`, then click window

**Where screenshots go**:
- Desktop first (automatic)
- Then you move them to their project folders

**File naming**: Always name them `screenshot.png`

## After All Screenshots Are Captured

## Tips

- Make Chrome window as large as possible before capturing
- If a page looks broken, try refreshing it first
- You can retake any screenshot if you're not happy with it
- The screenshots don't have to be perfect - just show the project clearly
