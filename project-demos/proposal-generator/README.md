# Business Tracker - Live Demo Version

## Overview

This is a generic, demo-ready version of the Business Tracker application with placeholder branding and comprehensive test data. Perfect for showcasing the application's capabilities without any company-specific information.

## Features Demonstrated

### 🎨 **Modern UI Design**
- **Theme Toggle**: Seamless dark/light mode switching
- **Enhanced Color Scheme**: Modern gradients and vibrant colors
- **Responsive Design**: Works perfectly on all device sizes
- **Glassmorphism Effects**: Beautiful transparent elements with blur effects

### 📊 **Dashboard Analytics**
- **Real-time Statistics**: Total opportunities, due this week, completed projects
- **Team Workload Visualization**: Progress bars showing team member workloads
- **Upcoming Opportunities**: Quick view of priority projects

### 📅 **Calendar View**
- **Interactive Calendar**: Click to view project details
- **Color-coded Events**: Tier-based color coding for quick identification
- **Hover Tooltips**: Detailed project information on hover

### 📋 **Table Management**
- **Advanced Filtering**: Filter by status, PM, tier, industry
- **Real-time Search**: Instant search across all project fields
- **Inline Editing**: Click any cell to edit directly
- **Bulk Actions**: Select multiple projects for batch operations
- **Sortable Columns**: Click headers to sort data

### ➕ **Project Wizard**
- **4-Step Process**: Guided project creation
- **Form Validation**: Real-time validation with helpful error messages
- **File Upload**: Document attachment capabilities
- **Tier Selection**: Visual tier selection with descriptions

### 📁 **Data Management**
- **Import/Export**: CSV import/export functionality
- **Template Download**: Pre-formatted CSV template
- **Data Persistence**: Browser localStorage for demo data

## Getting Started

1. **Open `index.html`** in any modern web browser
2. **Explore the Dashboard** to see project statistics
3. **Try the Theme Toggle** (moon/sun icon in header)
4. **Navigate between views** using the tab navigation
5. **Add a new project** using the "Add Opportunity" tab
6. **Filter and search** projects in the Table view
7. **Export data** using the Export button
